# Changelog

## 0.1.0

- First release.
- Open a JSON Schema (draft-04 to 2020-12, JSON or YAML) as docs: a property tree with types, required marks,
  rules and descriptions, with $ref followed in place, also into other local files. The text editor stays the default.
- Search properties, jump from a row to its line in the schema text.
- Validate JSON and YAML files against a local schema with ajv; errors in the Problems panel with path, line and rule.
- Remote $ref addresses are shown and never downloaded.
- Zovo Pro tools, one free try each: sample JSON and test data, docs export as Markdown or HTML, and schema diff.
