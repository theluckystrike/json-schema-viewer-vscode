# Sample JSON, docs export and schema diff

These Zovo Pro tools work on the schema in the docs view, or on a schema file you right-click in the Explorer. Each one has 1 free try.

- Generate sample JSON: one document with all fields, one with required fields only, or many documents of test data. Each is checked against the schema.
- Export docs: one Markdown file or one HTML page, a table of properties for each object.
- Schema diff: pick an older version of the schema and get a report with the breaking changes first.

Zovo Pro is USD 19 once, for every Zovo extension.
